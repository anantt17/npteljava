# NPTEL Java — Interactive Revision

I was going through the NPTEL *Programming in Java* course by Prof. Debasis Samanta (IIT Kharagpur) and got tired of re-reading the same PDFs. So I turned all 12 weeks of content into a single-file flashcard site I could actually study from.

## What's inside

- **1,800 flashcards** covering all 12 weeks — flip to reveal the answer
- **Concept notes** at the top of each week so you don't go in blind
- **Search** across every card in real time
- **Study mode** — fullscreen, keyboard-friendly drill session (Space to flip, arrow keys to navigate)
- **Progress tracking** — mark cards as mastered, it saves in your browser
- **Dark mode** because obviously

## Topics covered

Weeks 1–12: OOP basics → data types → scope & recursion → encapsulation → interfaces → exception handling → file I/O → applets → AWT → Swing → JDBC → mini project

## How to use

Just open `index.html` in a browser. No install, no setup, no internet needed (except for Google Fonts).

Or visit the live site → [npteljava.vercel.app](https://npteljava.vercel.app)
